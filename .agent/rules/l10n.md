# Localization Policy (l10n)

Every time you write or modify UI code:
1. **Never hardcode user-facing strings**: Do not put raw Malay or English strings in `Text(...)`, `showGlassToast(...)`, `InputDecoration(hintText: ...)`, button labels, or dialogs.
2. **Update localization dictionaries**: Add corresponding entries to both:
   - `C:/Project/Ngam/assets/translations/en.json`
   - `C:/Project/Ngam/assets/translations/ms.json`
3. **Keep 1:1 symmetry**: Every key in `en.json` must be present in `ms.json` with accurate translations.
4. **Use `.tr()`**: In Dart, import `'package:easy_localization/easy_localization.dart'` and use `'key.path'.tr()`.
